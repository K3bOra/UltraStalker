<a name="overview"></a>

<img src="assets/section-overview.svg" width="100%" alt="MEET ULTRA STALKER — Your receiver. Reimagined." />

**Ultra Stalker** brings Portal, Xtream and M3U services together with a premium media experience built for Enigma2 receivers. Go from Live TV to cinematic movie discovery, series, local media, favorites and global search without switching between plugins.

The interface is designed around elegant dark panels, subtle red-to-emerald accents, fast browsing, intelligent artwork caching and straightforward remote-control navigation.

> **Please note:** Ultra Stalker is a media interface. You must supply your own legal content sources. No subscriptions or copyrighted content are included.

<a name="installation"></a>

<img src="assets/section-installation.svg" width="100%" alt="READY TO GET STARTED? — One command. Your media in one place." />

**For compatible Enigma2 receivers** — open a terminal or Telnet/SSH session as root, then run the project's official installer:

```sh
wget -qO- https://raw.githubusercontent.com/K3bOra/-UltraStalker/main/install.sh | /bin/sh
```

Prefer reviewing the script first? [Read the official installer](install.sh) before running it.

**What the current installer checks:** Python 3.12–3.15, `opkg`, required libraries, available temporary storage and SHA-256 integrity of the downloaded IPK. The current installer targets **Ultra Stalker V9.2.2**. These version checks reflect the installer as published, rather than a guarantee of compatibility with every receiver or image.

**Manual package:** [Open the release asset used by the current installer](https://github.com/K3bOra/-UltraStalker/releases/download/v10.0.60/UltraStalker_V7_UPDATE.ipk).
**Version Clarification**

Ultra Stalker V9.2.2 (Revision 569) is the current installed plugin version.

The GitHub Release tag `v10.0.60` identifies the release containing the downloadable IPK package. It is not the installed plugin version.

The official `update.json` manifest remains the authoritative source for online updates.

> Installation and update steps require receiver access and may restart Enigma2. Back up important receiver configuration first.
